# Relay v2 — deploy runbook

The whole production stack lives on **one EC2 t4g.small** (Ubuntu 22.04, ARM)
behind nginx + Let's Encrypt TLS. Four processes:

```
relayed.live (443/80) ──► nginx ──► /api/* ──► uvicorn (127.0.0.1:8000)  [relay-api]
                                  └─► /*    ──► next start (127.0.0.1:3006) [relay-ui]
                                                                          │
                                                                          ▼
                                  Slack Socket Mode (outbound)            │
                                       ▲                                  │
                                       │                                  ▼
                                   [relay-bridge]                    Postgres 16
```

All three services share `/etc/relay/secrets.env` (mode 0640 root:relay) via
systemd `EnvironmentFile=`. The Postgres password + JWT secret + AES master
key are generated by `bootstrap.sh` on first run.

## First-time deploy

Assumes you have an Ubuntu 22.04 host with SSH access + DNS pointing at it.

```bash
# 1. SSH into the box (note: relay-v2 SSH key in .lightsail/relay-v2)
ssh -i .lightsail/relay-v2 ubuntu@<public-ip>

# 2. Clone + run bootstrap
sudo git clone https://github.com/shanerlevy-debug/relay-v2.git /opt/relay
sudo bash /opt/relay/deploy/bootstrap.sh

# 3. Paste Slack credentials into /etc/relay/secrets.env
sudo vi /etc/relay/secrets.env
#  OAUTH_SLACK_CLIENT_ID=...
#  OAUTH_SLACK_CLIENT_SECRET=...
#  RELAY_SLACK_APP_TOKEN=xapp-...

# 4. Provision TLS (DNS must already resolve)
sudo certbot --nginx -d relayed.live --non-interactive --agree-tos \
    -m you@yourdomain.com

# 5. Start services
sudo systemctl enable --now relay-api relay-bridge relay-ui

# 6. Verify
curl -s http://127.0.0.1:8000/api/health  # API ok + db ok
curl -sI https://relayed.live | head -1   # HTTP/2 200
```

## Subsequent updates

```bash
ssh -i .lightsail/relay-v2 ubuntu@<public-ip>
sudo /opt/relay/deploy/redeploy.sh
```

`redeploy.sh` pulls main, conditionally reinstalls deps if `pyproject.toml`
or `package.json` changed, applies new alembic migrations, rebuilds the UI
if any `ui/` file changed, reloads nginx if `nginx.conf` changed, and
restarts the three services. Idempotent — safe to run any time. Logs to
`/var/log/relay/redeploy.log`.

## Operations

```bash
# Tail all three services
sudo journalctl -u relay-api -u relay-bridge -u relay-ui -f

# Restart one
sudo systemctl restart relay-api

# Check status
sudo systemctl status relay-api relay-bridge relay-ui

# Postgres CLI as the relay user
sudo -u postgres psql relay

# Read latest redeploy log
sudo tail -f /var/log/relay/redeploy.log
```

## TLS renewal

certbot installs a renewal cron + systemd timer automatically. Verify with:

```bash
sudo systemctl list-timers | grep certbot
sudo certbot renew --dry-run
```

## File layout on the box

```
/opt/relay/                       Git checkout (owned by relay:relay)
├── api/                          FastAPI gateway
│   └── .venv/                    Python venv with relay-api -e
├── bridge/                       Multi-tenant Slack bridge
│   └── .venv/                    Python venv with relay-api + relay-bridge -e
├── ui/                           Next.js production build
│   └── .next/                    Build output
└── deploy/                       This directory

/etc/relay/                       Secrets + config (mode 0750 root:relay)
└── secrets.env                   Single env file for all 3 services (mode 0640)

/var/lib/relay/                   App-writable state (currently empty)
/var/log/relay/                   App + deploy logs
└── redeploy.log                  Update history

/etc/systemd/system/relay-{api,bridge,ui}.service
/etc/nginx/sites-available/relay  Symlinked into sites-enabled
/etc/letsencrypt/live/relayed.live/  TLS certs + key
```

## Quick reference: troubleshooting

| Symptom | Where to look | Likely cause |
|---|---|---|
| 502 Bad Gateway on https://relayed.live | `journalctl -u relay-ui` | Next.js failed to build or didn't start. Check `ui/.next` exists |
| 502 on /api/* only | `journalctl -u relay-api` | uvicorn crashed. Common: missing env var in secrets.env |
| Bridge isn't responding to Slack | `journalctl -u relay-bridge` | RELAY_SLACK_APP_TOKEN missing or wrong scopes |
| signup returns 500 | `journalctl -u relay-api` then check Postgres | Migration not applied — run `alembic upgrade head` from `/opt/relay/api` |
| Postgres is OOM-killed | `dmesg \| grep -i kill` | Tune `shared_buffers` lower in `/etc/postgresql/*/main/postgresql.conf` |
| Certbot renewal failed | `sudo certbot renew --dry-run` | Usually DNS or rate limits — see certbot's output |
